# Спазган® от боли и спазмов — доработка текста страницы

Прототип страницы препарата Спазган с SEO-правками текста.

## Что внутри

| Файл | Что это |
|---|---|
| `index.html` | Разводящая страница со ссылками на все материалы |
| `spasgan-desktop.html` | Прототип посадочной (десктоп + адаптив) |
| `spasgan-mobile.html` | Прототип в рамке телефона (390 px) |
| `spasgan-presentation.html` | Презентация «Было → Стало → Зачем» по текстовым правкам |

Статичные HTML без сборки — открываются двойным кликом или с любого статик-хостинга.

## Что сделано

Сравнение с текущей страницей [spasgan.ru/spasgan](https://spasgan.ru/spasgan/):

- Ключевой запрос добавлен в H1, фирменный слоган сохранён
- Список из 30+ диагнозов переупакован в 10 понятных карточек с пояснениями живым языком
- Блок «Активные вещества» переписан как «Три компонента против боли и спазма» — с ролью каждого и выводом
- Отстройка от обычного анальгетика вынесена в отдельный блок сравнения
- Добавлен блок доверия (E-E-A-T): ГРЛС, безрецептурный отпуск, цитата врача, дата проверки
- FAQ расширен с 1 вопроса до 11, включая вопрос о противопоказаниях
- Мобильная версия синхронизирована с десктопной по содержанию

Ни один факт с исходной страницы не выброшен — менялась подача, а не состав информации.

## Локально

Открыть `index.html` в браузере.

## Деплой

Статика в корне репозитория, конфигурация не требуется.

## Требует данных от клиента

- **Длительность приёма** — на сайте указано «не более 5 дней», в макете «3 дня без консультации врача». Расхождение фактическое, нужно привести к инструкции
- **Противопоказания** — перечень в FAQ собран по общей фармакологии действующих веществ, **нужно сверить с официальной инструкцией (РУ ЛП-003270)** перед публикацией
- ФИО и должность врача-рецензента + дата проверки материала
- Ссылки на инструкцию, согласие на обработку ПД, политику конфиденциальности
- Виджет карты аптек вместо плейсхолдера
- Фото упаковки в фирменном стиле вместо CSS-мокапа
